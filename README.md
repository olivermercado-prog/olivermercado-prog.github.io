# Sitio de CV de Oliver Uriel Sánchez Mercado

Sitio estático publicado con GitHub Pages en https://olivermercado-prog.github.io/

## Archivos
- `index.html`: CV en inglés
- `es/index.html`: CV en español
- `assets/styles.css`: estilos
- `downloads/`: CV en PDF (inglés y español)
- `.nojekyll`: archivo vacío para que GitHub publique el HTML tal cual

## Cómo actualizar
1. Entra a la carpeta del archivo en el repositorio.
2. *Add file → Upload files* y sube el archivo nuevo con el mismo nombre.
3. Confirma en la rama `main` y espera unos minutos.
4. Abre el sitio en una ventana privada y revisa el cambio y las descargas.
